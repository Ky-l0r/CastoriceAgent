CastoriceAgent 使用说明
============================================================

遐蝶是一个跑在 Windows 桌面上的 AI 陪伴助手：有性格、会发表情、
记得住你们聊过的事。程序绿色便携，不需要安装 Python，
整个文件夹删掉就等于卸载。

更详细的图文说明见项目主页：
https://github.com/Ky-l0r/CastoriceAgent


------------------------------------------------------------
一、第一次使用（必看）
------------------------------------------------------------
1. 双击 CastoriceAgent.exe 启动（首次启动会慢几秒，属正常）。

   如果 Windows 弹出蓝色的「Windows 已保护你的电脑」提示，
   点「更多信息 → 仍要运行」即可——程序没有购买数字签名，不是病毒。

2. 还没填过 API Key 时，程序会自动弹出「设置」窗口，
   聊天区也会提示你先去配置。

3. 在「设置」窗口里：
     · 提供商：从下拉框里选一个（openai / deepseek / aliyun / custom）
     · API Key：填入你自己的密钥（形如 sk-xxxxxxxx）
     · Base URL、模型：一般保持默认即可，换服务商时才需要改
     · Temperature：可留空
     · 点「保存」

4. 关掉设置窗口，回到聊天框就能开始对话了。

提示：Key 需要到 AI 服务商官网注册后自行创建，例如
        DeepSeek    https://platform.deepseek.com
        阿里云百炼   https://bailian.console.aliyun.com
      任何兼容 OpenAI 接口的服务都可以用。
      本软件免费，但调用模型是按量计费的，需要先充值。

提示：也可以直接编辑程序目录下的 config.yaml，效果完全一样。
      设置窗口保存时会保留文件里的注释，两种方式可以混用。


------------------------------------------------------------
二、目录说明
------------------------------------------------------------
CastoriceAgent.exe   主程序（不要单独拖出来，它需要旁边的 _internal）
_internal\           程序依赖的库，不要删除或改名
config.yaml          配置：模型提供商、API Key、表情包频率、搜索等
prompts\             角色设定（性格、语气、世界观等），可自行修改
                     *.md / *.txt 会被按文件名顺序拼接进提示词
Image\CastoriceAvatar.jpeg   聊天头像，换成同名文件即可
Image\CastoriceAgent.ico     exe 图标，一般不用动
Image\表情包\         表情包图片，文件名就是表情名称
database\            对话记忆数据库（自动生成，删掉即清空记忆）
memory\              结构化记忆落盘（自动生成，与 database 一起删=清空记忆）
sessions\            各模式的对话记录（自动生成，按模式分目录；
                      只想清对话记录就删它，不影响记忆）
schedules.json       主动聊天的定时任务（自动生成，见第十节）
channels\            渠道数据目录（启用 QQ 渠道后自动生成）
logs\app.log         运行日志，出问题时先看这里
ui_settings.json     界面设置（显示模式），自动生成

注意：请把整个文件夹放在有写入权限的位置（如桌面、D 盘），
      不要放在 C:\Program Files，否则程序无法创建记忆库和日志。


------------------------------------------------------------
三、日常操作
------------------------------------------------------------
发送消息    Enter 发送，Shift + Enter 换行
发表情包    点输入框旁的笑脸按钮，选中后插入输入框，可继续补文字
发图片      点图片按钮选图，图片挂在输入框上方（点 × 移除），
            可再输入文字一起发送
切换主题    右上角齿轮 → 外观
复制消息    鼠标直接拖选文字
移动窗口    按住标题栏拖动


------------------------------------------------------------
三·一、四种工作模式（新）
------------------------------------------------------------
聊天界面右上角可以切换四种模式，每个模式的对话历史相互独立：

  聊天  纯对话，AI 没有任何工具，也不会执行任何操作
  工作  通用工具全开（搜索 / 读写文件 / 跑命令等），
        可以在右侧面板绑定一个工作目录
  编程  面向代码目录的文件与命令工具集
  学习  对接 Obsidian Vault 的笔记读写与检索

有副作用的操作（写文件、跑命令）执行前会弹出审批条，
请在倒计时内点「允许」或「拒绝」——不回应就按拒绝处理，
不会自动放行。

进阶设置在 config.yaml 的 mode / modes / permissions / memory 节：
  · mode            启动时进入的模式（chat | work | code | learn）
  · modes.<名字>.sandbox   该模式的沙箱级别，优先级最高；
                    其次是 permissions.sandbox_default，
                    再次是程序内置默认值；写错会回落到下一级
  · memory          记忆引擎选择（embedding | wiki | summary）
这几个节缺失时，程序启动会按默认值自动补齐并给出提示。

安全说明：工具的目录与命令限制是程序内的策略检查，不是进程或
文件系统级的硬隔离；请只在可信的目录绑定与命令白名单下使用。


------------------------------------------------------------
四、显示模式
------------------------------------------------------------
右上角齿轮按钮 →「外观」里可选：
  · 跟随系统（默认，跟着 Windows 的深色/浅色设置走）
  · 浅色（白色偏紫）
  · 深色（黑色偏紫）
选择会记在 ui_settings.json 里，下次启动自动恢复。


------------------------------------------------------------
五、发送图片给 AI 看（需要视觉模型）
------------------------------------------------------------
如果当前模型支持图片输入，输入区会出现「图片」按钮：

1. 点它选择图片，图片会显示在输入框上方（可点 × 移除）
2. 可以再输入一段文字，然后按 Enter 一起发送
3. AI 就能看到图片内容了

模型是否支持图片输入，由程序按模型名自动判断
（如 *-vl、gpt-4o、claude-3 等视为视觉模型）；
也可以在「设置」里手动勾选「该模型支持图片输入」。

看不到图片按钮，就说明当前模型不被识别为视觉模型。


------------------------------------------------------------
六、添加自己的表情包
------------------------------------------------------------
1. 把图片（png / jpg / jpeg / webp / gif / bmp）放进
   Image\表情包\ 目录，文件名就是表情名称，例如「开心.png」。

2. 想让 AI 在合适的情绪下发出它，可以在 config.yaml 的
   emoji.keywords 里补上对应心情关键词，例如：

     emoji:
       keywords:
         开心: ["开心", "高兴", "太好了", "哈哈"]

   不补也能用，只是会由程序随机兜底挑选。

3. 表情包出现频率在 config.yaml 的 emoji 段调整：
     probability      发出概率（0.35 表示约三成回复会带表情）
     cooldown_turns   发过一次后至少隔几轮才可能再发
     max_per_session  每次启动最多发几个，0 表示不限制


------------------------------------------------------------
七、清空记忆 / 备份 / 卸载
------------------------------------------------------------
清空记忆   删掉 database\ 与 memory\ 目录，下次启动会自动重建空库
清空对话   只想删各模式的聊天记录时，删 sessions\ 目录即可
备份       把整个文件夹复制走即可
卸载       把整个文件夹删掉，不留任何残留

警告：分享给别人之前，请先把 config.yaml 里的 API Key 删掉或清空。
      里面存的是你的密钥，别人拿到可以直接用你的额度。


------------------------------------------------------------
八、常见问题
------------------------------------------------------------
Q：双击没反应，或提示缺少文件？
A：多半是没解压完整。确认 exe 旁边有 _internal 文件夹，
   并且是「整个文件夹」解压出来的，而不是只把 exe 拖出来。

Q：杀毒软件报毒，或 Windows 提示「已保护你的电脑」？
A：没有数字签名的 exe 常见误报，PyInstaller 打包的程序尤其容易遇到。
   点「更多信息 → 仍要运行」，或把它加入安全软件的信任名单。

Q：发消息后提示鉴权失败 / 401？
A：API Key 没填或填错了，去「设置」里重新填。
   也检查一下服务商账户里是否还有余额。

Q：提示模型不存在？
A：模型名写错了。到服务商官网查一下准确的模型名，
   在「设置」里改「模型」这一栏。

Q：AI 回复很慢或没反应？
A：先看 logs\app.log。若是网络问题，检查 Base URL 是否能访问
   （部分服务商需要科学上网）。

Q：怎么清空聊天记忆？
A：删掉 database\ 和 memory\ 目录即可，下次启动会自动重建空库；
   只想清对话记录（不影响记忆）就删 sessions\。

Q：AI 为什么有时候不发表情包？
A：这是故意的。默认约三成概率附带表情，避免每条都刷图。
   想调高就把 config.yaml 里 emoji.probability 改成 0.8，
   或设成 1.0 让它每条都发。

Q：界面太暗 / 太亮？
A：点右上角齿轮 → 外观，可选「跟随系统 / 浅色 / 深色」。

Q：换了显示模式后没生效？
A：主题是即时生效的，如果没变化请重启程序再看。

Q：启动有点慢？
A：文件夹版首次启动约 2~5 秒，要加载本地检索库，属正常现象。


------------------------------------------------------------
九、接入 QQ（NapCat，进阶）
------------------------------------------------------------
遐蝶可以通过 NapCat 接入 QQ：程序作为客户端，连到 NapCat 开的
「反向 WebSocket」服务上收发消息。需要先部署 NapCat
（https://github.com/NapNeko/NapCatQQ）。

1. 在 NapCat 里开启 WebSocket 服务端，记下监听地址
   （如 ws://127.0.0.1:3001）和 access token。
2. 编辑程序目录下的 config.yaml，取消 channels 节的注释并填写：

     channels:
       napcat:
         url: "ws://127.0.0.1:3001"     # NapCat 反向 WS 地址（必填）
         access_token: "your-token"     # NapCat 的 token，建议必填
         allowed_senders: []            # 发送者 QQ 号白名单，空=不限制
         allowed_groups: []             # 群号白名单，空=不限制
         default_chat_type: "private"   # 裸数字 chat_id 归属: private|group
         max_chunk_len: 4500            # 长文本分段长度
         report_tools: false            # true 时工具事件折叠成提示

3. 重启程序。首次连接会做校验：地址连不上或 token 错误会直接报错，
   不会出现「看似在线实际收不到消息」的情况；断线会自动重连，
   重复推送的消息会去重，不会重复回复。

安全建议：务必设置 access_token，并用 allowed_senders /
allowed_groups 限制谁能触发你的 AI——群里任何 @ 到 bot 的人
都可能消耗你的 API 额度。


------------------------------------------------------------
十、主动聊天（定时任务，进阶）
------------------------------------------------------------
遐蝶可以定时主动找你说话：在程序目录的 schedules.json 里登记
定时任务（该文件由程序运行时生成与更新，不随发布包分发），
到点后她按 proactive_message 生成一段主动的话，投递到目标。

一条任务的格式示例：

  {
    "id": "morning-greeting",            // 唯一标识
    "title": "早安问候",                  // 最长 120 字符
    "triggers": {"daily": "08:30"},      // 触发器，五选一互斥：
                                         //   after_seconds: 3600
                                         //   at: "2026-05-01T09:00:00"
                                         //   every_seconds: 7200
                                         //   daily: "08:30"
                                         //   weekly: "10:00" + weekday: 0-6
    "proactive_message": "早上好，跟她打个招呼",
    "targets": [
      {"id": "desktop:main"},            // 桌面气泡通知
      {"id": "qq:123456789",             // QQ 私聊/群（需已接入 NapCat）
       "fallback": "desktop"}            // 渠道离线回退: desktop|skip
    ],
    "enabled": true
  }

投递保证：
  · 只补发最近一次错过的时点——错过 3 个时点也只发 1 条；
  · 先落盘、后投递——崩溃重启不会重复发同一条；
  · 触发精度为分钟级（秒字段被忽略）。
