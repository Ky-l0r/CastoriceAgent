CastoriceAgent 使用说明
============================================================

一、第一次使用（必看）
------------------------------------------------------------
1. 双击 CastoriceAgent.exe 启动。
2. 如果还没填过 API Key，程序会自动弹出「设置」窗口，
   聊天区也会提示你先去配置。
3. 在「设置」窗口里：
     · 提供商：从下拉框里选一个（openai / deepseek / aliyun / custom）
     · API Key：填入你自己的密钥（形如 sk-xxxxxxxx）
     · Base URL、模型：一般保持默认即可，换服务商时才需要改
     · 点「保存」
4. 关掉设置窗口，回到聊天框就能开始对话了。

提示：也可以直接编辑程序目录下的 config.yaml，效果完全一样。
      设置窗口保存时会保留文件里的注释，两种方式可以混用。


二、目录说明
------------------------------------------------------------
CastoriceAgent.exe   主程序
config.yaml          配置：模型提供商、API Key、表情包频率、搜索等
prompts\             角色设定（性格、语气、世界观等），可自行修改
                     *.md / *.txt 会被按文件名顺序拼接进提示词
Image\CastoriceAvatar.jpeg   聊天头像，换成同名文件即可
Image\表情包\         表情包图片，文件名就是表情名称
database\            对话记忆数据库（自动生成，删掉即清空记忆）
logs\app.log         运行日志，出问题时先看这里
ui_settings.json     界面设置（显示模式），自动生成


三、添加自己的表情包
------------------------------------------------------------
1. 把图片（png / jpg / webp / gif）放进 Image\表情包\ 目录，
   文件名就是表情名称，例如「开心.png」。
2. 想让 AI 在合适的情绪下发出它，可以在 config.yaml 的
   emoji.keywords 里补上对应心情关键词，例如：

     emoji:
       keywords:
         开心: ["开心", "高兴", "太好了", "哈哈"]

   不补也能用，只是会由程序随机兜底挑选。

3. 表情包出现频率在 config.yaml 的 emoji 段调整：
     probability      发出概率（0.35 表示约三成回复会带表情）
     cooldown_turns   发过一次后至少隔几轮才可能再发


四、发送图片给 AI 看（需要视觉模型）
------------------------------------------------------------
如果当前模型支持图片输入，输入框下面会出现「图片」按钮：

1. 点它选择图片，图片会显示在输入框上方（可点 × 移除）
2. 可以再输入一段文字，然后按 Enter 一起发送
3. AI 就能看到图片内容了

模型是否支持图片输入，由程序按模型名自动判断
（如 *-vl、gpt-4o、claude-3 等视为视觉模型）；
也可以在「设置」里手动勾选「该模型支持图片输入」。


五、常见问题
------------------------------------------------------------
Q：发消息后提示鉴权失败 / 401？
A：API Key 没填或填错了，去「设置」里重新填。

Q：提示模型不存在？
A：模型名写错了。到服务商官网查一下准确的模型名，
   在「设置」里改「模型」这一栏。

Q：AI 回复很慢或没反应？
A：先看 logs\app.log。若是网络问题，检查 Base URL
   是否能访问（部分服务商需要科学上网）。

Q：怎么清空聊天记忆？
A：删掉 database\ 目录即可，下次启动会自动重建空库。

Q：界面太暗 / 太亮？
A：点右上角齿轮 → 外观，可选「跟随系统 / 浅色 / 深色」。

Q：换了显示模式后没生效？
A：主题是即时生效的，如果没变化请重启程序再看。


六、显示模式
------------------------------------------------------------
右上角齿轮按钮 → 「外观」里可选：
  · 跟随系统（默认，跟着 Windows 的深色/浅色设置走）
  · 浅色（白色偏紫）
  · 深色（黑色偏紫）
选择会记在 ui_settings.json 里，下次启动自动恢复。
